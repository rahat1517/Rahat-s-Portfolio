// FEATURED PROJECT · AI AGENT
Offline Bank AI Agent

Ask a banking database questions in Bangla or Banglish, with no internet needed

An AI assistant that answers questions about customers, accounts, cards, loans and transactions by turning natural-language questions into SQL. It runs 100% offline on a local LLM, so sensitive banking data never leaves the machine, and it replies in Bangla or Banglish.

  • Intent router sends each question to the SQL generator or general Q&A
  • LLM-generated SQL runs through a read-only runner, so the database can't be changed
  • 8-table SQLite banking schema: branches, customers, accounts, transactions, cards, loans, loan payments, employees
  • Remembers the last 4 turns, so follow-up questions work
  • Response formatter turns query results into readable answers
  • Streamlit chat interface on top of a local Ollama model (Qwen2.5-Coder 1.5B)
PythonOllamaQwen2.5-CoderSQLiteStreamlitText-to-SQL
🤖 Runs fully offline
